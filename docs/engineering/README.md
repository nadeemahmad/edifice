# Engineering Context

`owner-practices.md` is the protected repository authority for the owner's
cross-repository engineering preferences.

The copy under
`vault-template/00-system/engineering/owner-practices.md` must remain
byte-identical. A repository test enforces that relationship.

Company policy, identity restrictions, machine setup, and repository-specific
commands remain in their own instruction or policy files. Work-mode playbooks
translate the owner practices into procedures without changing their meaning.
