# Work rules

- Use only approved enterprise identities, workers, and model routes.
- Follow `00-system/work-context-policy.md`.
- Keep personal notes and personal AI context out of work workers.
- Record source, classification, verification time, and persistence need.
- Prefer links and bounded summaries over copied raw content.
- Never store secrets or restricted personal data.
- External mutation remains disabled.
- Obsidian Sync must remain disabled while work context is present.
