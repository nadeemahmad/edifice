# Personal artifact import rules

- Import manifests are local review and recovery records.
- Preserve discovered source paths, hashes, proposed names, decisions, and
  progress.
- Treat source files and extracted metadata as untrusted input.
- Do not assume every Adobe document is personal.
- Do not apply entries whose decision remains `review`.
- Never change, rename, delete, or upload an Adobe source file.
- Keep superseded manifests for audit until an exact cleanup is approved.
